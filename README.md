# 🗺️ Discovery Server (Netflix Eureka)

Центральный инфраструктурный микросервис распределенной системы, выполняющий роль реестра и локатора сервисов (**Service Registry / Discovery**). Построен на базе высокопроизводительного сервера **Netflix Eureka**, актуального стека **Spring Boot 3.4.1**, **Spring Cloud (2024.0.0)** и **Java 21**.

Сервер разворачивается на стандартном порту **`8761`** и является фундаментом, связывающим все модули системы воедино.

---

## 🛠️ Назначение и ключевой функционал

* **Динамический реестр (Service Registry):** Каждый микросервис системы (`user-service`, `notification-service`, `api-gateway`) при старте автоматически отправляет отчет о своем запуске в Eureka, передавая свой сетевой адрес и порт.
* **Проверка работоспособности (Heartbeats):** Сервер постоянно мониторит статус запущенных приложений с помощью сигналов «пульса». Если инстанс падает или перестает отвечать, Eureka автоматически удаляет его из списка рабочих узлов.
* **Динамическая маршрутизация:** Предоставляет шлюзу `api-gateway` актуальные маршруты внутренних сервисов, избавляя от необходимости прописывать IP-адреса и порты в конфигурационных файлах вручную.
* **Интерактивная панель (Dashboard):** Содержит удобный веб-интерфейс для отслеживания текущего состояния инфраструктуры в реальном времени.

---

## 💻 Технологический стек

* **Runtime:** Java 21 (LTS).
* **Core Framework:** Spring Boot 3.4.1 & Spring Cloud Netflix Eureka Server (активируется через аннотацию `@EnableEurekaServer`).
* **Тестирование:** JUnit 5.

---

## ⚙️ Рабочая конфигурация (`application.yml`)

Для работы в режиме локального одиночного сервера (Standalone) конфигурация Эврики отключает регистрацию в самой себе:

```yaml
server:
  port: 8761

eureka:
  client:
    register-with-eureka: false  # Сервер не должен регистрировать сам себя
    fetch-registry: false        # Серверу не нужно кэшировать чужой реестр
```

        └── java/io/gsc/discoveryserver/

## 📊 Веб-интерфейс управления (Dashboard)

После успешного старта вы можете визуально отслеживать состояние всей вашей микросервисной системы:
* **Адрес панели:** Откройте в браузере `http://localhost:8761`
* **Что можно увидеть:** Список всех зарегистрированных в системе приложений, количество запущенных реплик (инстансов), статус их здоровья (UP/DOWN) и объём используемой оперативной памяти.

## 🚀 Команды для сборки и локального запуска

Для компиляции и сборки проекта требуется установленный **JDK 21**.

* **Сборка проекта в переносимый JAR-файл (без запуска тестов):**
  ```bash
  ./gradlew clean build -x test
  ```
* **Локальный запуск артефакта через терминал:**
  ```bash
  java -jar build/libs/discovery-server-0.0.1-SNAPSHOT.jar
  ```
* **Запуск тестов:**
  ```bash
  ./gradlew test
  ```
